# Отчёт по товарам с обязательной маркировкой

- Адрес: https://seller.wildberries.ru/instructions/ru/kz/material/goods-with-mandatory-labeling-report-kazakhstan
- Идентификатор: A-1323
- Обновлено: 2026-05-18T11:09:05.698119Z

---
> **Примечание**
>
> Эта статья — для продавцов из Казахстана 🇰🇿

После того, как вы продали товары, промаркированные КИЗ, в этом [отчёте](https://seller.wildberries.ru/analytics-reports/excise-report) вы получаете информацию о том, какие из кодов были проданы.

![image.png](https://static-basket-02.wbbasket.ru/vol20/article-static/fa89b027-2d6b-40b7-9d9e-98e751b83cc4.webp)

Выберите диапазон дат и страну, чтобы увидеть данные. Таблицу можно выгрузить и сохранить на компьютер в виде Excel-документа.

При доставке на склады Wildberries товары, которые подлежат обязательной маркировке, продавец получает сведения о кодах маркировки (КИЗ) по отгруженным товарам.

По актам приёмки УПД «ДОП» формируется автоматически. Скачайте документ «УПД по маркировке» из раздела «[Документы](https://seller.wildberries.ru/supplementary-agreements)» в профиле на портале. После ознакомления отправьте нам файл в формате XML через вашего оператора ЭДО.
