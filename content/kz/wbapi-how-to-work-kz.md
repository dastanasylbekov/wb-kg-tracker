## Что такое WB API

**WB API (Application Programming Interface)** — программный интерфейс, который позволяет сторонним сервисам и собственным программам продавцов обмениваться информацией с магазином продавца на Wildberries. Благодаря интеграциям по WB API вы сможете автоматизировать процессы управления магазином, ускорить работу и масштабировать бизнес.

## Для чего WB API нужен продавцам

Используя WB API, вы сможете управлять магазином на Wildberries и получать данные не только вручную через личный кабинет или приложение, но и с помощью сторонних или собственных решений. WB API даёт возможность:

- упростить и ускорить ежедневные операции,
- автоматизировать работу с товарами и рекламой,
- узнавать о новых заказах по факту их создания и оперативно отправлять на сборку, а затем анализировать данные по продажам,
- обмениваться данными с внутренними учётными системами, например, 1С,
- упростить обработку отзывов и вопросов от покупателей, например, с помощью решений для быстрой генерации готовых ответов.

## Какие системы можно использовать для интеграции

- **Каталог готовых решений** — проверенные сторонние сервисы, которые уже интегрированы с WB API и готовы к быстрому подключению. Помогут вам начать автоматизацию, если вы не хотите или не можете создать самостоятельную интеграцию. Каталог доступен [на странице бизнес-решений WB API](https://dev.wildberries.ru/en/business-solutions).
- **Другие готовые решения**, которые работают с WB Partners, но пока не добавлены в каталог.
- **Ваши собственные информационные системы**, для которых вы можете самостоятельно написать интеграцию со своим магазином на WB Partners.

## Как подключиться по API к магазину

Есть два способа подключить сторонний готовый сервис или собственную информационную систему к магазину продавца на WB Partners:

### Подключение через токен

Способ подходит для собственных разработок или сторонних решений, которые не поддерживают OAuth 2.0. Для подключения вы вручную создаёте специальный токен (ключ доступа), который будет использоваться для получения доступа к вашему магазину при обмене данными со сторонним сервисом или вашей информационной системой.

> **Примечание**
>
> Подробнее об этом методе подключения читайте [в отдельной инструкции](https://seller.wildberries.ru/instructions/ru/kz/material/api-integration-with-token-kz)

### Подключение через OAuth 2.0

Более безопасный и удобный способ подключения сторонних сервисов. Используется для сервисов из каталога готовых решений. Он обеспечивает надёжную защиту ваших данных и не требует управления токенами.

> **Совет**
>
> Мы рекомендуем использовать интеграцию через OAuth 2.0, если сервис её поддерживает, так как это более простой, удобный и безопасный способ работы с WB API

Если сервис не поддерживает OAuth 2.0 или вы используете собственные разработки, выбирайте подключение через токен.

> **Примечание**
>
> Подробнее об этом методе подключения читайте [в отдельной инструкции](https://seller.wildberries.ru/instructions/ru/kz/material/oauth20-api-integration-kz)
