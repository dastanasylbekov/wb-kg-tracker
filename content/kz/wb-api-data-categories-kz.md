## Что такое категории данных и зачем они нужны

Категории данных — это набор разрешений, который определяет, к какой информации вашего магазина на Wildberries получит доступ подключённый сервис или программа.

Когда вы создаёте токен для подключения внешней системы к профилю, нужно выбрать одну или несколько категорий данных. Категории, которые вы выбрали, определяют, к каким данным вашего профиля система или сотрудник получат доступ и что они смогут с ними делать.

![](https://static-basket-02.wbbasket.ru/vol20/article-static/0a5eef36-2419-450f-8bf2-7c8aa0d25db6.webp)

**Зачем выбирать категории данных:**

- безопасность — даже если токен попадёт в чужие руки, доступ будет только к тем данным, которые вы указали в настройках токена,
- контроль — вы точно знаете, к какой информации имеет доступ каждая внешняя система,
- удобство — можно быстро отключить доступ выбранного сервиса к вашему профилю. Для этого достаточно отозвать токен, который выдан сервису. При этом другие подключённые системы сохранят доступ к данным, если используют собственные токены.

Например, если вы подключаете сервис для автоматической публикации ответов на отзывы, ему нужна только категория «Вопросы и отзывы».

> **Важно**
>
> Важно:после создания токена изменить выбранные категории нельзя — нужно создать новый токен;один токен может давать доступ к нескольким категориям. Не рекомендуем выбирать больше 3 категорий данных для персонального и базового токенов; для разных сервисов лучше создавать отдельные токены с разными наборами категорий. Если через один токен подключено несколько внешних систем, и вам потребуется забрать доступ у одной из них, после отзыва токена доступ прекратится для всех систем, которые используют этот токен.

## Какие категории данных есть в WB API

В WB API есть 13 категорий данных. Каждая категория отвечает за определённую область работы вашего магазина. Ниже мы подробно разберём каждую из них.

### Контент

Эта категория нужна для управления карточками товаров в вашем магазине. С ней можно:

- создавать новые карточки товаров,
- редактировать существующие карточки: названия, описания, характеристики,
- загружать и изменять фотографии и видео товаров,
- получать категории и характеристики товаров,
- работать с метками (тегами) для группировки товаров.

**Выбирайте категорию «Контент», если:**

- вы автоматически загружаете товары из вашей системы учёта в магазин на Wildberries,
- вы хотите, чтобы результаты редактирования, например, описаний или характеристик в вашей системе, автоматически применялись на Wildberries,
- вы используете сервис для оптимизации описаний карточек товаров.

> **Примечание**
>
> Пример: ваш склад работает в системе 1С, и вы хотите автоматически добавлять новые товары на Wildberries, как только они появляются в вашей базе. Для интеграции понадобится категория «Контент»

### Аналитика

Эта категория нужна, чтобы получать подробную аналитику по продажам и работе вашего магазина. С ней можно:

- смотреть воронку продаж: сколько людей открыли карточку товара, добавили в корзину и купили ваш товар,
- анализировать поисковые запросы покупателей,
- получать отчёты по остаткам товаров на складах,
- смотреть продажи по регионам,
- анализировать долю вашего бренда в общих продажах,
- получать отчёты по возвратам товаров,
- смотреть данные по платному хранению и операциям при приёмке.

**Выбирайте категорию «Аналитика», если:**

- вы подключаете сервис аналитики, чтобы отслеживать эффективность продаж,
- вам нужно автоматически получать отчёты для принятия бизнес-решений,
- вы анализируете спрос на товары и планируете закупки.

> **Примечание**
>
> Пример: вы хотите понять, какие товары лучше продаются в разных регионах, чтобы скорректировать рекламную стратегию. Подключайте аналитический сервис с категорией «Аналитика»

### Цены и скидки

Эта категория нужна для управления ценами на товары и участия в акциях Wildberries. С ней можно:

- изменять цены на товары,
- устанавливать и редактировать скидки,
- получать информацию об акциях на платформе,
- автоматически добавлять товары в акции.

**Выбирайте категорию «Цены и скидки», если:**

- вы автоматически меняете цены на свои товары в зависимости от цен конкурентов,
- вы устанавливаете скидки на группы товаров или отдельные товары через вашу систему.

> **Примечание**
>
> Пример: у вас есть система, которая помогает управлять ценами на товары, автоматически корректируя их в зависимости от вашей стратегии. Этой системе нужна категория «Цены и скидки»

### Маркетплейс

Эта категория данных нужна для управления заказами и складскими операциями. С ней можно:

- работать с заказами по моделям «Маркетплейс» (FBS), «Витрина» (DBS), «Витрина экспресс» (EDBS), «Самовывоз из магазина продавца» (C&C),
- управлять складами по этим моделям,
- обновлять остатки товаров на складах продавца.

**Выбирайте категорию «Маркетплейс», если:**

- вы работаете по моделям продаж «Маркетплейс» (FBS), «Витрина» (DBS), «Витрина экспресс» (EDBS) и «Самовывоз из магазина продавца» (C&C),
- вам нужно автоматически передавать информацию о заказах в вашу систему учёта,
- вы автоматически обновляете остатки товаров на своих складах.

> **Примечание**
>
> Пример: вы отгружаете заказы со своего склада и хотите, чтобы информация о новых заказах автоматически попадала в вашу складскую систему. Нужна категория «Маркетплейс»

### Статистика

Эта категория нужна, чтобы получить данные детализаций к отчётам реализации, а также списки заказов и продаж.

> **Обратите внимание**
>
> В будущем для доступа к данным отчётов реализации потребуется категория «Финансы». Мы заранее сообщим об этом в «Новостях»

С этой категорией можно:

- получать детализации отчётов реализации,
- анализировать финансовые показатели магазина.

**Выбирайте категорию «Статистика», если:**

- вам нужна подробная статистика для бухгалтерии,
- вы автоматически формируете финансовые отчёты,
- вы анализируете рентабельность каждого товара.

> **Примечание**
>
> Пример: ваш бухгалтер работает в специальной программе, которая автоматически получает финансовые отчёты из Wildberries и формирует налоговую отчётность. Этой программе нужна категория «Статистика»

### Продвижение

Эта категория данных нужна для управления рекламными кампаниями на платформе Wildberries. С ней можно:

- создавать рекламные кампании и управлять ими,
- изменять ставки для продвижения товаров,
- следить за бюджетом рекламных кампаний,
- получать статистику по эффективности рекламы,
- получать информацию и статистику о кампаниях WB Медиа.

**Выбирайте категорию «Продвижение», если:**

- вы используете автоматизированные системы для управления рекламой,
- вам нужно корректировать ставки для товаров через вашу систему,
- вы подключаете сервис для оптимизации рекламных расходов.

> **Примечание**
>
> Пример: вы используете сервис, который автоматически повышает ставки на товары с хорошей конверсией и снижает на неэффективные. Ему нужна категория «Продвижение»

### Вопросы и отзывы

Эта категория нужна для работы с отзывами покупателей и ответов на их вопросы. С ней можно:

- получать список новых отзывов и вопросов,
- отвечать на отзывы покупателей,
- отвечать на вопросы о товарах.

> **Важно**
>
> Категория данных «Вопросы и отзывы» позволяет работать только с данными отзывов и вопросов покупателей. Для общения с покупателями в чате Wildberries подключите отдельную категорию «Чат с покупателями»

**Выбирайте категорию «Вопросы и отзывы», если:**

- вы автоматически получаете уведомления о новых отзывах,
- вы используете сервис для управления репутацией,
- вам нужно быстро реагировать на вопросы покупателей.

> **Примечание**
>
> Пример: вы подключили сервис, который автоматически отправляет уведомления в Telegram о каждом новом отзыве, чтобы вы могли быстро на него отреагировать. Ему нужна категория «Вопросы и отзывы»

### Чат с покупателем

Эта категория нужна для общения с покупателями в чате на платформе Wildberries. С ней можно:

- получать сообщения от покупателей,
- отправлять ответы покупателям,
- просматривать историю переписки,
- работать с жалобами покупателей в чате.

> **Важно**
>
> Категория данных «Чат с покупателем» даёт возможность только общаться с покупателями в чате. Для работы с отзывами и вопросами покупателей подключите отдельную категорию «Вопросы и отзывы»

**Выбирайте категорию «Чат с покупателем», если:**

- вы используете внешнюю CRM-систему для обработки обращений покупателей,
- вам нужно, чтобы сообщения из чата Wildberries приходили в вашу систему поддержки.

> **Примечание**
>
> Пример: у вас большой магазин с отделом поддержки, который работает в единой CRM-системе. Вы хотите, чтобы все сообщения покупателей из чата Wildberries тоже попадали туда. Нужна категория «Чат с покупателем»

### Поставки

Эта категория нужна для формирования и управления поставками товаров на склады Wildberries, если вы работаете по модели «Склад WB» (FBW). С ней можно:

- получать информацию для формирования поставок,
- получать список доступных складов и транзитных направлений,
- просматривать информацию о поставках,
- получать информацию обо всех товарах в поставке.

**Выбирайте категорию «Поставки», если:**

- вы работаете по модели «Склад WB» (FBW), когда товары хранятся на складах Wildberries,
- вам нужно планировать поставки с учётом коэффициентов приёмки.

> **Примечание**
>
> Пример: вы используете специальный сервис, который анализирует продажи, остатки и коэффициенты приёмки, а затем подсказывает, когда и на какой склад лучше отправить новую поставку. Ему нужна категория «Поставки»

### Возвраты

Эта категория нужна для обработки заявок на возврат от покупателей. С ней можно:

- получать информацию о заявках на возврат товаров,
- обрабатывать заявки на возврат.

**Выбирайте категорию «Возвраты», если:**

- вам нужно автоматически получать информацию о заявках на возврат в вашу систему учёта,
- вы анализируете причины возвратов для улучшения качества товаров.

> **Примечание**
>
> Пример: вы хотите автоматически получать уведомления обо всех заявках на возврат и анализировать, какие товары возвращают чаще всего и почему. Нужна категория «Возвраты»

### Документы

Эта категория данных нужна для получения актов, УПД, печатных форм отчётов и других документов, которые поступают в раздел «Документы» на портале WB Partners.

> **Примечание**
>
> Выбирайте категорию «Документы», если ваша бухгалтерия использует специальную программу, которая автоматически скачивает все УПД и акты из Wildberries и загружает их в 1С. Ей нужна категория «Документы»

### Финансы

С этой категорией можно проверять текущий баланс магазина.

> **Обратите внимание**
>
> В будущем с этой категорией можно будет получать списки отчётов реализации и детализации финансовых отчётов

Выбирайте категорию «Финансы», если:

- вам нужно автоматически отслеживать баланс,
- вы используете сервис финансового учёта, который собирает информацию о балансах со всех ваших торговых площадок в одном месте.

### Пользователи

Эта категория нужна для управления доступами пользователей, которые подключены к вашему личному кабинету. С ней можно:

- пригласить нового сотрудника и сразу настроить его права;
- посмотреть, кто уже работает в кабинете, а кто пока только приглашён;
- изменить права доступа для любого пользователя;
- отозвать доступ, если сотрудник больше не работает с порталом.

> **Важно**
>
> Управлять доступом других пользователей может только владелец профиля — для этого понадобится персональный токен. В базовом или сервисном токене категория «Пользователи» недоступна

Выбирайте категорию «Пользователи», если у вас несколько сотрудников и вы хотите разграничить их доступ к личному кабинету и разделам портала.

## Методы, доступные с любой категорией данных

В WB API есть несколько методов, которые работают с любым токеном, кроме тестового. Чтобы ими пользоваться, не нужно выбирать специальные категории данных — подойдёт любой активный токен.

К таким методам относятся:

- «Тарифы» — информация [о тарифах Wildberries;](https://seller.wildberries.ru/dynamic-product-categories/delivery)
- «Новости» — [новости](https://seller.wildberries.ru/news-v2/news-list) и обновления платформы;
- «Информация о продавце» (seller-info) — базовые сведения о вашем магазине.

Эти методы предоставляют общую справочную информацию и не требуют доступа к данным конкретных категорий.

## Как правильно выбрать категории

При выборе категорий данных для токена следуйте простым правилам.

**1. Давайте доступ только к тем категориям, которые реально нужны для работы сервиса**

Чем меньше данных доступно через токен, тем меньше рисков при его утечке. Например, если вы подключаете сервис для работы с отзывами, давайте доступ только к категории «Вопросы и отзывы» — больше ничего для работы этого сервиса не нужно.

**2.  Уточняйте у разработчика или сервиса**

Если вы не уверены, какие категории нужны:

- для собственных систем — спросите у вашего разработчика или ответственного за систему сотрудника,
- для сервисных токенов — все нужные категории выбираются автоматически, когда вы создаёте токен.

**3.  Создавайте отдельные токены для разных задач**

Не используйте один токен для всех интеграций. Если вы подключили несколько систем, создайте для каждой отдельный токен с нужными категориями. Это упростит управление и повысит безопасность.

> **Примечание**
>
> Пример:токен № 1 для сервиса аналитики: категория «Аналитика»,токен № 2 для системы управления заказами: категория «Маркетплейс»,токен № 3 для сервиса работы с отзывами: категория «Вопросы и отзывы».

Если токен одного сервиса стал доступен третьим лицам, удалите его. Остальные интеграции продолжат работать, а магазин останется защищённым.

**4.  Помните про уровень доступа**

Кроме выбора категорий, при создании токена вы также выбираете уровень доступа:

- «только чтение» — можно получать данные вашего магазина, но нельзя изменять их,
- «чтение и запись» — можно и получать, и изменять данные.

Если системе нужно только смотреть данные — например, для аналитики, — выбирайте «только чтение» — это безопаснее.

> **Примечание**
>
> [Как создать, обновить или удалить токен WB API](https://seller.wildberries.ru/instructions/ru/kz/material/how-to-create-update-or-delete-a-wb-api-token-kazakhstan)

## Сценарии использования

Разберём несколько типичных ситуаций и нужные категории для каждой.

### Сценарий № 1. Подключение сервиса аналитики

Вы хотите подключить сервис, который будет показывать дашборды с аналитикой по продажам, остаткам и конкурентам.

**Нужные категории:**

- «Аналитика» — для получения данных о воронке продаж и поисковых запросах,
- «Статистика» (опционально) — если нужны детализации к отчётам реализации.

**Уровень доступа:** «только чтение» — сервис не будет ничего менять, только читать данные.

### Сценарий № 2. Автоматическая загрузка товаров из 1С

Товары появляются в вашей 1С, и вы хотите, чтобы они автоматически загружались на Wildberries со всеми фотографиями и описаниями.

**Нужные категории:**

- «Контент» — для создания и редактирования карточек товаров,
- «Цены и скидки» (опционально) — если нужно также автоматически устанавливать цены.

**Уровень доступа:** «чтение и запись» — нужно создавать новые карточки.

### Сценарий № 3. Управление рекламными кампаниями

Вы используете сервис для автоматического управления рекламой: он анализирует эффективность и корректирует ставки.

**Нужные категории:**

- «Продвижение» — для создания кампаний, изменения ставок и получения статистики,
- «Аналитика» (опционально) — если сервис также анализирует общую эффективность продаж для принятия решений о рекламе.

**Уровень доступа:** «чтение и запись» — нужно менять ставки и параметры кампаний.

### Сценарий № 4. Обработка заказов с отгрузкой со склада продавца

Вы работаете по одной из моделей продаж с отгрузкой со своего склада — FBS, DBW, DBS, EDBS или C&C. Вы хотите, чтобы новые заказы автоматически попадали в вашу складскую систему.

**Нужные категории:**

- «Маркетплейс» — для получения информации о заказах и обновления их статусов.

**Уровень доступа:** «только чтение» для получения заказов или «чтение и запись» — если также нужно обновлять статусы заказов.

### Сценарий № 5. Комплексное управление магазином

Вы используете мощную ERP-систему, которая управляет всеми аспектами работы магазина: от загрузки товаров до финансового учёта.

**Нужные категории:**

- «Контент» — управление карточками товаров,
- «Цены и скидки» — управление ценами,
- «Маркетплейс» — работа с заказами, которые вы отгружаете со своего склада,
- «Поставки» — работа с поставками по модели «Склад WB» (FBW),
- «Аналитика» — получение аналитики,
- «Статистика» — детализации отчётов реализации, списки заказов и продаж,
- «Документы» — получение УПД и актов,
- «Финансы» — отслеживание баланса.

**Уровень доступа:** «чтение и запись» — система должна полностью управлять магазином.

### Сценарий № 6. Работа с отзывами и коммуникацией

Вы хотите оперативно отвечать на отзывы и вопросы покупателей, а также общаться с ними в чате.

**Нужные категории:**

- «Вопросы и отзывы» — для работы с отзывами и вопросами о товарах,
- «Чат с покупателем» — для общения в чате.

**Уровень доступа:** «чтение и запись» — нужно публиковать ответы.

## Важные напоминания

### О безопасности

- токены дают доступ к данным вашего магазина — храните их надёжно,
- не выдавайте доступ к категориям данных, которые не обязательны для работы системы,
- создавайте отдельные токены для разных сервисов и задач,
- регулярно проверяйте список активных токенов в разделе «Интеграции по API».

### О смене владельца кабинета

Если владелец профиля на портале WB Partners изменится, токены могут перестать корректно работать. Новому владельцу нужно создать токены заново. Рекомендуем фиксировать, какие токены вы создавали и для каких интеграций, чтобы при необходимости быстро их восстановить.

### О сроке действия токенов

Токены действуют 180 дней. За 3 дня до окончания срока действия токена владельцу профиля на портале WB Partners придёт уведомление в «колокольчик». Не забывайте вовремя обновлять токены, иначе интеграции перестанут работать.

### О тестовых токенах

Тестовые токены используют для разработки и проверки интеграций в тестовом контуре WB API. У них есть особенности, которые отличают их от обычных токенов.

**Главное отличие:** при создании тестового токена не нужно выбирать категории данных. Он автоматически получает доступ на чтение и запись ко всем категориям, которые доступны в тестовом контуре.

Это удобно для разработчиков — можно сразу тестировать любые методы API без создания нескольких токенов с разными наборами категорий.

**Важно учитывать:**

- тестовые токены работают только в тестовом контуре и не дают доступа к реальным данным вашего магазина;
- список доступных категорий в тестовом контуре может отличаться от списка для обычных токенов;
- актуальный список методов и категорий для тестового контура всегда можно найти [в документации API](https://dev.wildberries.ru/sandbox).

Чтобы работать с реальными данными магазина, используйте обычные типы токенов и выбирайте для них нужные категории данных.
