> **Важно**
>
> Некоторые товары[запрещены к продаже](https://static-basket-02.wbbasket.ru/vol20/folder/restricted/Perechen_zapreshchennykh_tovarov_Respubliki_Kazahstan_20250210.pdf)

Управлять остатками можно в разделе [Поставки и заказы → Свой склад → Управление остатками](https://seller.wildberries.ru/marketplace-stocks-management). Здесь же можно отслеживать и редактировать информацию об уже загруженных остатках.

![](https://static-basket-02.wbbasket.ru/vol20/article-static/0f949b9d-fb76-425f-8b78-732a0c277875.webp)

На этой странице через строку поиска можно найти товар по наименованию, артикулу продавца или баркоду. Также вы можете отфильтровать товары по предмету, бренду, количеству, складу или ярлыку:

![](https://static-basket-02.wbbasket.ru/vol20/article-static/f554f0df-0fad-4b1d-8f88-36312e9ae80d.webp)

Есть 3 способа управлять остатками:

- вручную — удобно, если нужно добавить немного товаров,
- через XLSX-шаблон — для большого количества товаров.
- по[API](https://dev.wildberries.ru/openapi/work-with-products#tag/Ostatki-na-skladah-prodavca) — выбирайте этот способ, если наименований более 25 000. Подробнее о WB API читайте [в статье «Что такое WB API и как с ним работать».](https://seller.wildberries.ru/instructions/ru/kz/material/A-1150)

## Загрузить остатки вручную

1. Зайдите [в раздел «Управление остатками»](https://seller.wildberries.ru/marketplace-stocks-management) и нажмите кнопку «Добавить товары вручную».![](https://static-basket-02.wbbasket.ru/vol20/article-static/e2411bb8-6e46-4072-9351-085896c3bfb1.webp)
2. В списке слева выберите склад, который создали. Он должен соответствовать вашей модели продаж: «Витрина» (DBS) или «Витрина экспресс» (EDBS).
3. Проставьте галочки рядом с товарами, которые хотите добавить. Товары можно найти по наименованию, артикулу продавца, баркоду или фильтрам по предмету, бренду и ярлыку.
4. В колонке справа укажите количество.
5. Нажмите «Добавить» в правом верхнем углу.

![](https://static-basket-02.wbbasket.ru/vol20/article-static/10f68b22-394c-48da-86d8-b790641c3a1b.webp)

> **Обратите внимание**
>
> Заказы поступают на каждый склад в соответствии с остатками, которые вы указали для него. Будьте внимательны при загрузке остатков на конкретный склад. Если товара не будет в наличии и вы не сможете отправить его покупателю, начислим штраф за невыполненные заказы

## Загрузить остатки через XLSX-шаблон

1. [В разделе «Управление остатками»](https://seller.wildberries.ru/marketplace-stocks-management) нажмите кнопку «Действия с Excel». В выпадающем списке выберите «Скачать шаблон».

![](https://static-basket-02.wbbasket.ru/vol20/article-static/c97bec1a-a2d2-4e02-8da1-e49a7a32a8f2.webp)

Шаблон — это таблица из двух колонок: «Баркод» и «Количество».

![](https://static-basket-02.wbbasket.ru/vol20/article-static/875ad306-849b-49ca-ab6b-90af83e6ec51.webp)

> **Примечание**
>
> Скачать информацию о баркодах можно в разделе [Товары и цены → Карточка товара](https://seller.wildberries.ru/new-goods/all-goods). Нажмите на «Загрузки» в верхнем меню:![](https://static-basket-02.wbbasket.ru/vol20/article-static/3265afc7-2126-4582-a200-5db18c8b2e61.webp)В правом верхнем углу выберите «Баркоды». Отфильтруйте товары, баркоды которых вы хотите загрузить, и нажмите «Скачать данные». ![](https://static-basket-02.wbbasket.ru/vol20/article-static/d8df06b6-6e44-4893-ae97-69426a6425c4.webp)

2. Введите данные в шаблон: укажите каждый баркод и количество товара по нему в отдельной строке. Сохраните заполненную таблицу.

![](https://static-basket-02.wbbasket.ru/vol20/article-static/af422366-4682-40e5-a066-617bafa0cdce.webp)

> **Важно**
>
> Для правильной работы шаблона не меняйте таблицу. Вводите только нужные числовые данные без пробелов и других знаков

3. Нажмите на кнопку «Действия с Excel» и выберите «Загрузить файл с товарами».

![](https://static-basket-02.wbbasket.ru/vol20/article-static/d21c7b13-57c4-4785-a51d-2ffb0abfafe0.webp)

4. В появившемся окне выберите склад, который создали. Он должен соответствовать вашей модели продаж: «Витрина» (DBS) или «Витрина экспресс» (EDBS).
5. Загрузите файл и нажмите «Сохранить».В появившемся окне выберите склад, который работает по модели DBS, и загрузите файл. Затем нажмите «Сохранить».

![](https://static-basket-02.wbbasket.ru/vol20/article-static/a1790e99-43b8-4ec7-b8e0-675e4dd359d1.webp)

> **Важно**
>
> В XLSX-шаблоне нельзя указывать остатки с нулевым количеством — только больше 0. Если хотите указать, что товара на складе не осталось, измените остаток вручную

Информация на сайте и в приложении для покупателей обновляется в течение 15 минут с момента загрузки изменений. Когда покупатель закажет ваш товар, остатки уменьшатся автоматически.

Если покупатель отменил заказ до отправки товара на сборку, остаток не увеличится автоматически — это необходимо будет сделать вручную. Заказы, которые покупатели отменили, появляются в разделе [Поставки и заказы → Свой склад → Витрина (DBS) → Отменённые](https://seller.wildberries.ru/marketplace-orders-dbs/canceled):

![](https://static-basket-02.wbbasket.ru/vol20/article-static/4b9576fb-7f92-40e0-aea8-b3882f4be7bd.webp)

## Редактировать остатки

Загруженные остатки можно отредактировать в любой момент. Чтобы сделать это вручную, нажмите «Фильтры» → «Склад» и выберите склад по модели «Витрина» (DBS) или «Витрина экспресс» (EDBS). Найдите нужный товар, поменяйте значение в колонке «Количество товаров» и нажмите на галочку.

![](https://static-basket-02.wbbasket.ru/vol20/article-static/ce5742c3-055b-4956-92ed-4ed0c15d121a.webp)

Также можно загрузить обновлённый XLSX-файл, как описано выше в разделе «Загрузить остатки через XLSX-шаблон».

## Выгрузить остатки в XLSX-файл

Чтобы выгрузить остатки по одному из складов, нажмите «Действия с Excel» → «Выгрузить файл с товарами».

![](https://static-basket-02.wbbasket.ru/vol20/article-static/ca0bc426-bb95-404f-8808-3fd338f439ee.webp)

В открывшемся окне выберите склад и нажмите «Скачать Excel».

![](https://static-basket-02.wbbasket.ru/vol20/article-static/91483bbe-0d25-4c83-93b3-daba3ad4b4be.webp)

> **Важно**
>
> В XLSX-выгрузке доступно не более 25 000 строк. Если у вас больше наименований товаров, используйте [API](https://seller.wildberries.ru/instructions/ru/kz/material/A-1150)

## Как управлять остатками в мобильном приложении WB Partners

### нажмите, чтобы развернуть

Перейдите в раздел «Свой склад» и нажмите на виджет «Остатки».

Чтобы добавить товары вручную:

1. Нажмите кнопку «Добавить вручную».
2. Выберите склад по модели DBS или EDBS.
3. Найдите нужные товары, укажите их количество и нажмите «Добавить».

![image.png](https://static-basket-02.wbbasket.ru/vol20/article-static/bd21d428-4f28-4834-a60e-2ff6c35e587b.webp)

Чтобы изменить остатки через Excel:

1. Нажмите «Действия с Excel».
2. Скачайте и заполните шаблон, если требуется.
3. Выберите «Выгрузить файл с товарами».
4. Выберите нужный склад, загрузите заполненный файл со своего устройства и нажмите «Загрузить файл с товарами».

![image.png](https://static-basket-02.wbbasket.ru/vol20/article-static/ac22e55a-3f3b-42c0-b54a-9f9626848c20.webp)
