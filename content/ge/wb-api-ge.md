Вы можете управлять своим магазином не только через веб-версию портала WB Partners, но и с помощью собственных программ. Их можно подключить к вашему магазину при помощи WB API.

## Что такое WB API

WB API (Application Programming Interface) — программный интерфейс, который позволяет сторонним сервисам и собственным программам продавцов обмениваться информацией с магазином продавца на Wildberries. Благодаря интеграциям по WB API вы сможете автоматизировать процессы управления магазином, ускорить работу и масштабировать бизнес.

## Для чего WB API нужен продавцам

Используя WB API, вы сможете управлять магазином на Wildberries и получать данные не только вручную через личный кабинет, но и с помощью собственных решений. WB API даёт возможность:

- упростить и ускорить ежедневные операции,
- автоматизировать работу с товарами и рекламой,
- узнавать о новых заказах по факту их создания и оперативно отправлять на сборку, а затем анализировать данные по продажам,
- обмениваться данными с внутренними учётными системами (например, 1С),
- упростить обработку отзывов и вопросов от покупателей (например, с помощью решений для быстрой генерации готовых ответов).

> **Обратите внимание**
>
> Для интеграции вы можете использовать ваши собственные информационные системы, для которых вы можете самостоятельно написать интеграцию со своим магазином на WB Partners. Подключить сторонние сервисы пока не получится

## Как подключиться по API к магазину

Чтобы подключить собственную информационную систему к магазину продавца на WB Partners, создайте специальный токен (ключ доступа). Он будет использоваться для получения доступа к вашему магазину при обмене данными с вашей информационной системой.

Токен можно создать на портале WB Partners в разделе «[Интеграция по API](https://seller.wildberries.ge/api-integrations)».
