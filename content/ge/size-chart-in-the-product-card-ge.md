# Таблица размеров в карточке товара

Чтобы покупателям было легче разобраться, какой размер товара заказать, продавцы могут добавить таблицу размеров в карточку. Можно выбрать одну из стандартных таблиц размеров.

## Добавить стандартную таблицу

В разделе «Товары и цены» → Карточка товара создайте новую карточку товара и укажите его категорию. Либо выберите уже готовую карточку и нажмите «Редактировать карточку».

Если для этой категории доступны таблицы размеров, на странице редактирования карточки появится поле «Таблица размеров». Система покажет список подходящих таблиц размеров для категории вашей карточки. Выберите нужную.

## Добавить размеры из таблицы в карточку товара

После того, как вы добавите в карточку стандартную таблицу, на странице создания карточки появятся поля для ввода размера.

Введите размер, который указан на вашем товаре, выберите соответствующий ему размер из таблицы. Добавьте баркод для этого варианта товара.

![Поиск и фильтр.png](https://static-basket-02.wbbasket.ru/vol20/article-static/4b96fdeb-6c2b-4844-b684-abe86e6cbf72.png.webp)

Далее нажмите «+ Добавить размер» и введите данные для следующего размера.
