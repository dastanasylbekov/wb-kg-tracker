შეგიძლიათ მართოთ თქვენი მაღაზია არა მხოლოდ WB Partners პორტალის ვებ-ვერსიის მეშვეობით, არამედ საკუთარი პროგრამების გამოყენებითაც. მათი თქვენს მაღაზიასთან დაკავშირება შესაძლებელია WB API-ის მეშვეობით.

## რა არის WB API?

WB API (Application Programming Interface) – პროგრამული ინტერფეისია, რომელიც მესამე მხარის სერვისებსა და სელერების საკუთარ პროგრამებს საშუალებას აძლევს გაცვალონ ინფორმაცია სელერის მაღაზიასთან Wildberries-ზე. WB API-ის ინტეგრაციების მეშვეობით შეძლებთ მაღაზიის მართვის პროცესების ავტომატიზაციას, სამუშაო პროცესის დაჩქარებას და ბიზნესის მასშტაბირებას.

## რისთვის სჭირდებათ სელერებს WB API?

WB API-ის გამოყენებით შეგიძლიათ მართოთ თქვენი მაღაზია Wildberries-ზე და მიიღოთ მონაცემები არა მხოლოდ პირადი კაბინეტის მეშვეობით ხელით, არამედ საკუთარი გადაწყვეტების გამოყენებითაც. WB API საშუალებას გაძლევთ:

●      გაამარტივოთ და დააჩქაროთ ყოველდღიური ოპერაციები,

●      მოახდინოთ პროდუქტებთან და რეკლამასთან მუშაობის პროცესების ავტომატიზაცია,

●      მიიღოთ ინფორმაცია ახალი შეკვეთების შესახებ მათი შექმნისთანავე, ოპერატიულად გაგზავნოთ ისინი მოსამზადებლად და შემდეგ განახორციელოთ გაყიდვების მონაცემების ანალიზი,

●      გაცვალოთ მონაცემები შიდა აღრიცხვის სისტემებთან (მაგალითად, 1С),

●      გაამარტივოთ მყიდველების გამოხმაურებებისა და კითხვების დამუშავება (მაგალითად, მზა პასუხების სწრაფად გენერირების გადაწყვეტების გამოყენებით).

> **Обратите внимание**
>
> ინტეგრაციისთვის შეგიძლიათ გამოიყენოთ თქვენი საკუთარი საინფორმაციო სისტემები, რისთვისაც შეგიძლიათ დამოუკიდებლად შექმნათ ინტეგრაცია თქვენს მაღაზიასთან WB Partners-ზე. მესამე მხარის სერვისების დაკავშირება ამ ეტაპზე შეუძლებელია

## როგორ დავუკავშირდეთ მაღაზიას API-ს მეშვეობით

საკუთარი საინფორმაციო სისტემის დასაკავშირებლად სელერის მაღაზიასთან WB Partners-ზე, შექმენით სპეციალური ტოკენი (წვდომის გასაღები). ის გამოყენებული იქნება თქვენს საინფორმაციო სისტემასთან მონაცემების გაცვლისას თქვენს მაღაზიაზე წვდომის მისაღებად.

ტოკენის შექმნა შესაძლებელია WB Partners პორტალზე განყოფილებაში „[ინტეგრაცია API-ს მეშვეობით](https://seller.wildberries.ge/api-integrations)“.
