После того как вы создали [карточки товаров](https://seller.wildberries.ru/instructions/ru/ru/subcategory/how-to-create-item-card) и [склад,](https://seller.wildberries.ru/instructions/ru/ru/material/click-and-collect-model#%D1%81%D0%BE%D0%B7%D0%B4%D0%B0%D0%B9%D1%82%D0%B5-%D1%81%D0%BA%D0%BB%D0%B0%D0%B4%C2%A0) нужно указать информацию об остатках — то есть количестве товаров, которое есть у вас в наличии.

> **Важно**
>
> Некоторые товары[запрещены к продаже](https://static-basket-02.wbbasket.ru/vol20/portal/education/instruction/Perechen_zapreshchennykh_tovarov.pdf). Для модели «Самовывоз» есть исключения — можно размещать карточки:
>
> - алкогольной продукции,
> - фармацевтических товаров,
> - ветеринарных рецептурных препаратов.
>
> Чтобы создать карточки таких товаров, создайте обращение в службу поддержки в категории «Маркетплейс: Самовывоз из магазина продавца» с темой «Алкогольная и фармацевтическая продукция: вопросы о работе».
>
> По Федеральному закону от 22.11.1995 № 171-ФЗ дистанционная продажа таких товаров запрещена. Разрешено только бронирование заказа. Продажа и оплата происходят на месте — при получении

Управлять остатками можно в разделе [Поставки и заказы → Свой склад → Управление остатками](https://seller.wildberries.ru/marketplace-stocks-management). Здесь же можно отслеживать и редактировать информацию об уже загруженных остатках.

![](https://static-basket-02.wbbasket.ru/vol20/article-static/2e878a7b-c122-49e1-be1f-b8c42f12ba7d.webp)

На этой странице выберите вкладку «Самовывоз». Через строку поиска можно найти товар по наименованию, артикулу продавца или баркоду. Также вы можете отфильтровать товары по предмету, бренду или ярлыку:

![](https://static-basket-02.wbbasket.ru/vol20/article-static/bde5bdca-7810-48a6-a24e-4539e19486e5.webp)

Есть три способа управлять остатками:

- вручную — удобно, если нужно добавить немного товаров;
- через XLSX-шаблон — для большого количества товаров;
- по[API](https://dev.wildberries.ru/openapi/work-with-products#tag/Ostatki-na-skladah-prodavca) — выбирайте этот способ, если наименований более 25 000. Подробнее о WB API читайте [в статье «Что такое WB API и как с ним работать».](https://seller.wildberries.ru/instructions/ru/by/material/wbapi-how-to-work-by?goBackOption=prevRoute&categoryId=0198ad35-0f5d-7428-98a9-7e28c7dff393)

## Загрузить остатки вручную

1. Зайдите в раздел и нажмите кнопку «Добавить товары вручную».![](https://static-basket-02.wbbasket.ru/vol20/article-static/0909e568-04bf-485c-afac-19d0140a8418.webp)
2. В списке слева выберите склад, который вы создали для работы по модели продаж «Самовывоз из магазина продавца» (C&C).
3. Проставьте галочки рядом с товарами, которые хотите добавить. Товары можно найти наименованию, артикулу продавца, баркоду или фильтрам по предмету, бренду и ярлыку.
4. В колонке справа укажите количество.
5. Нажмите «Добавить» в правом верхнем углу.

![](https://static-basket-02.wbbasket.ru/vol20/article-static/c2ca42d8-2b6e-4f39-ad86-a3601659f080.webp)

> **Обратите внимание**
>
> Заказы поступают на каждый склад в соответствии с остатками, которые вы указали для него. Будьте внимательны при загрузке остатков на конкретный склад. Если товара не будет в наличии и вы не сможете отправить его покупателю, начислим штраф за невыполненные заказы

## Загрузить остатки через XLSX-шаблон

1. На странице «Управление остатками» нажмите кнопку «Действия с Excel». Из выпадающего списка выберите «Скачать шаблон».

![](https://static-basket-02.wbbasket.ru/vol20/article-static/f204c090-6093-4c18-8919-8af5716b9d65.webp)

Шаблон — это таблица из двух колонок: «Баркод» и «Количество».

![](https://static-basket-02.wbbasket.ru/vol20/article-static/92cfe8e9-3a39-41e9-8f75-3e7a2b57fc65.webp)

> **Примечание**
>
> Скачать информацию о баркодах можно в разделе [Товары и цены → Карточка товара](https://seller.wildberries.ru/new-goods/all-goods). Нажмите на «Загрузки» в верхнем меню:![](https://static-basket-02.wbbasket.ru/vol20/article-static/09835fad-9ffb-443c-ace2-d4eb24343726.webp)В правом верхнем углу выберите «Баркоды». Отфильтруйте товары, баркоды которых вы хотите загрузить, и нажмите «Скачать данные». ![](https://static-basket-02.wbbasket.ru/vol20/article-static/11ac3e09-dcf4-486a-8094-d6b3a23b9d21.webp)

2. Введите данные в шаблон: укажите каждый баркод и количество товара по нему в отдельной строке. Сохраните заполненную таблицу.

![](https://static-basket-02.wbbasket.ru/vol20/article-static/c86e3fc4-9687-4480-bc7f-3c58c37c7f5a.webp)

> **Важно**
>
> Для правильной работы шаблона не меняйте таблицу. Вводите только нужные числовые данные без пробелов и других знаков

3. Нажмите на кнопку «Действия с Excel» и выберите «Загрузить файл с товарами».

![](https://static-basket-02.wbbasket.ru/vol20/article-static/c9b891f2-a8c5-4c39-a451-6d129b3ff579.webp)

4. В появившемся окне выберите склад, который работает по модели C&C, и загрузите файл. Затем нажмите «Сохранить».

![](https://static-basket-02.wbbasket.ru/vol20/article-static/e2dfd66d-7567-404c-8413-d85725117700.webp)

> **Важно**
>
> В XLSX-шаблоне нельзя указывать остатки с нулевым количеством — только больше 0. Если хотите указать, что товара на складе не осталось, измените остаток вручную

Информация на сайте и в приложении для покупателей обновляется в течение 15 минут с момента загрузки изменений. Когда покупатель закажет ваш товар, остатки уменьшатся автоматически.

Если покупатель отменил заказ до отправки товара на сборку, остаток не увеличится автоматически — это необходимо будет сделать вручную. Заказы, которые покупатели отменили, появляются в разделе [Поставки и заказы → Свой склад → Самовывоз → Отменённые](https://seller.wildberries.ru/marketplace-orders-click-and-collect/canceled):

![](https://static-basket-02.wbbasket.ru/vol20/article-static/081c3c3d-36c9-4052-8f69-0dc70a888968.webp)

## Редактировать остатки

Загруженные остатки можно отредактировать в любой момент. Чтобы сделать это вручную, нажмите «Фильтры» → «Склад» и выберите склад по модели «Самовывоз из магазина продавца» (C&C). Найдите нужный товар, поменяйте значение в колонке «Количество товаров» и нажмите на галочку.

![](https://static-basket-02.wbbasket.ru/vol20/article-static/029e78ae-a57c-48f0-95fe-71d36676b639.webp)

Также можно загрузить обновлённый XLSX-файл, как описано выше в разделе «Загрузить остатки через XLSX-шаблон».

## Выгрузить остатки в XLSX-файл

Чтобы выгрузить остатки по одному из складов, нажмите «Действия с Excel» → «Выгрузить файл с товарами».

![](https://static-basket-02.wbbasket.ru/vol20/article-static/9ffe19e7-2c32-4dc8-93b7-5805fca8e028.webp)

В открывшемся окне выберите склад и нажмите «Скачать Excel».

![](https://static-basket-02.wbbasket.ru/vol20/article-static/95583d87-5470-4e02-8b8a-f0a6242946a6.webp)

> **Важно**
>
> В XLSX-выгрузке доступно не более 25 000 строк. Если у вас больше наименований товаров, используйте [API](https://seller.wildberries.ru/help-center/article/A-433)
