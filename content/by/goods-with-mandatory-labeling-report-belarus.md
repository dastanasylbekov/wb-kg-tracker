# Отчёт по товарам с обязательной маркировкой

- Идентификатор: A-1321
- Обновлено: 2026-05-18T11:09:05.618059Z

---
> **Примечание**
>
> Эта статья — для продавцов из Беларуси 🇧🇾

После того, как вы продали товары, промаркированные СИ, в этом [отчёте](https://seller.wildberries.ru/analytics-reports/excise-report) вы получаете информацию о том, какие из кодов были проданы.

![image.png](https://static-basket-02.wbbasket.ru/vol20/article-static/451dcc51-a3d9-499b-9903-e4c6201bed62.webp)

Выберите диапазон дат и страну, чтобы увидеть данные. Таблицу можно выгрузить и сохранить на компьютер в виде Excel-документа.

При доставке на склады Wildberries товары, которые подлежат обязательной маркировке, продавец получает сведения о кодах маркировки (СИ) по отгруженным товарам.

По актам приёмки УПД «ДОП» формируется автоматически. Скачайте документ «УПД по маркировке» из раздела «[Документы](https://seller.wildberries.ru/supplementary-agreements)» в профиле на портале. После ознакомления отправьте нам файл в формате XML через вашего оператора ЭДО.
