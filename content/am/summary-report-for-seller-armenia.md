# Сводный отчёт по продавцу

- Идентификатор: A-1283
- Обновлено: 2026-05-18T11:09:04.073949Z

---
[Отчёт](https://seller.wildberries.ru/analytics-reports/summary-report) отображает основные показатели по продажам и обороту продавца без разбивки по брендам и номенклатурам, то есть являясь сводным по контрагенту. Данные приведены в виде таблицы.

![image.png](https://static-basket-02.wbbasket.ru/vol20/article-static/656df52b-9dc1-44b0-b4ec-7372d3b0bbc1.webp)

Вы можете выбрать показатели, которые хотите видеть в таблице, нажав кнопку «Настроить таблицу».

Нажмите на стрелочку возле года в первой колонке таблицы, чтобы развернуть данные и посмотреть отчёт по месяцам.
