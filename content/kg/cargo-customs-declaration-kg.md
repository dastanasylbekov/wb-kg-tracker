# Декларация на товары (Грузовая таможенная декларация)

Если ваши товары производятся не в странах ЕАЭС (Россия, Армения, Беларусь, Казахстан, Кыргызстан), вам понадобится номер декларации на товары — ДТ.

> **Совет**
>
> Декларацию на товары (ДТ) также иногда называют грузовой таможенной декларацией (ГТД). Это один и тот же документ

## Что такое ДТ

Декларация на товары (ДТ) — документ, который позволяет легально перевозить импортные товары через границу. В ДТ (ГТД) содержится информация о грузе, транспорте, таможенной стоимости товара, отправителе и получателе.

При импорте ДТ оформляют на таможне. При экспорте — проверяют, чтобы убедиться в правильности оформления вывоза.

## Зачем нужна ДТ

Номер ДТ (ГТД) для заказов по модели «Склад WB» (FBW) нужно указывать, если вы хотите продавать импортные товары за пределы ЕАЭС. Например, вы импортировали товары из Китая в Кыргызстан и хотите, чтобы их могли заказать покупатели из Грузии. Тогда для этих товаров нужно указать ДТ.

> **Важно**
>
> Если не указать номер ДТ (ГТД) для товара, и его закажет покупатель из-за пределов ЕАЭС, товар не пропустят на таможне

Для продажи импортных товаров в странах ЕАЭС декларация не обязательна. Если товары произведены внутри ЕАЭС, ГТД не нужна для их продажи в другие страны.

## Где найти номер ДТ

ДТ (ГТД) оформляют при ввозе товаров в страны ЕАЭС через таможню. Её номер указан в графе «А» — это код из цифр и знаков «/» длиной от 17 до 29 символов.

> **Примечание**
>
> Пример номера ДТ (ГТД): 10013160/151121/0715333

## Как добавить номер ДТ

После создания поставки в любой момент в неё можно внести номера деклараций.

1. Кликните на нужную поставку в разделе «Поставки и заказы» → «Поставки (FBW)» и перейдите на вкладку «ГТД».
2. Нажмите «Загрузить».

![](https://static-basket-02.wbbasket.ru/vol20/article-static/423ecaaf-753d-4b86-8dd4-2ff6c085468c.webp)

3. В открывшемся окне скачайте Excel-файл с шаблоном ДТ (ГТД).

![](https://static-basket-02.wbbasket.ru/vol20/article-static/0f41df4f-d394-48c2-bc5e-5eb94d31a513.webp)

**Правила заполнения шаблона**

1. В файле для каждого артикула нужно указать всего два значения: код страны происхождения и номер ДТ. Остальная информация подгрузится в файл автоматически, из данных о поставке.

![](https://static-basket-02.wbbasket.ru/vol20/article-static/4aa502d7-ba8f-4a5e-9441-e6d9e3d847ce.webp)

2. В столбце «Код страны происхождения» укажите коды из [Общероссийского классификатора стран мира](https://esnsi.gosuslugi.ru/classifiers/16269/data?pg=1&p=1) — это число от 1 до 999.
3. Убедитесь, что ДТ состоит только из цифр и символов «/», а длина номера — не более 29 символов.
4. Указывайте ДТ (ГТД) только для товаров из конкретной поставки. Файл не будет принят, если в нём указать товары не из поставки — даже если они есть в ДТ.
5. Если всего часть товаров в поставке привезены не из стран ЕАЭС, укажите номера ДТ (ГТД) только для этих товаров. Для остальных баркодов можно оставить поле ДТ (ГТД) пустым — эти строки удалять не обязательно.
6. Если на один товар оформлено несколько ДТ, добавьте для него новую строку с тем же баркодом и вторым номером ДТ.
7. Файл с ДТ (ГТД) можно заменить — просто загрузите новый документ в ту же поставку. Мы сотрём старые данные и учтём только последний успешно загруженный файл.

Если файл заполнен неверно, вы увидите сообщение об ошибке и подсказки, что следует исправить.

![](https://static-basket-02.wbbasket.ru/vol20/article-static/c0da8b42-1ae4-4860-a7d0-bfe38fe45996.webp)

Если всё заполнено верно, файл ДТ загрузится, и вы увидите на экране подтверждение.

![](https://static-basket-02.wbbasket.ru/vol20/article-static/5c81c352-c460-4f19-b1fe-a0e9cee52a64.webp)

В поставке на вкладке «ГТД» появится статус «Файл загружен».

![](https://static-basket-02.wbbasket.ru/vol20/article-static/e29b4d95-f086-4405-bb47-1cb3492011fe.webp)
