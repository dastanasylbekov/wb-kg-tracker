# Ярлыки для фильтрации товаров

> **Примечание**
>
> Эта статья — для продавцов из Кыргызстана ![🇰🇬](https://static-basket-02.wbbasket.ru/vol20/article-static/287dd5c0-42b3-4d70-8e5e-5d0f053693ca.webp)

С помощью ярлыков вы можете разделить свои карточки на удобные группы, по которым потом их можно фильтровать. Например, можно разделить сезонные товары или добавить ярлык «Архив» для товаров, которые больше не продаются.

Ярлыки не влияют на объединение и разъединение карточек.

> **Обратите внимание**
>
> Можно добавить **до 15 ярлыков**. Длина ярлыка — **до 15 символов**.

> **Примечание**
>
> Раньше ярлыки назывались тегами.

### Как добавить ярлык товару

Зайдите: Личный кабинет → Товары → найдите нужный товар в таблице и нажмите + в колонке «Ярлыки».

![](https://static-basket-02.wbbasket.ru/vol20/article-static/5291c883-8c60-400c-a723-b864f793752e.webp)

Введите название нового ярлыка. Нажмите название или Enter, чтобы сохранить ярлык.

![](https://static-basket-02.wbbasket.ru/vol20/article-static/3e8cc04a-dd5f-420f-bb27-c97fd70969ca.webp)

![](https://static-basket-02.wbbasket.ru/vol20/article-static/e1406f3a-b1ae-403d-b3b2-b468939d1ffa.webp)

Чтобы отредактировать или удалить ярлык, нажмите на него, а затем — три точки справа от названия.

![](https://static-basket-02.wbbasket.ru/vol20/article-static/dfbba86e-0af1-41e9-8b0e-98fb312aa7b4.webp)

### Как добавить ярлыки сразу нескольким товарам

Зайдите: Личный кабинет → Товары → слева над таблицей товаров нажмите Добавить →  Присваивание ярлыков.

![](https://static-basket-02.wbbasket.ru/vol20/article-static/6702b522-a492-4b65-ac58-f135f05856a8.webp)

Скачайте шаблон, заполните его и загрузите готовый файл.

![](https://static-basket-02.wbbasket.ru/vol20/article-static/751cc643-2b77-44e3-bce2-ec672dd44b04.webp)

Нажмите Обновить ярлыки.

> **Важно**
>
> При загрузке шаблона старые ярлыки удаляются, если есть новые. Чтобы удалить сразу все ярлыки, оставьте пустой ячейку ярлыков в таблице.
